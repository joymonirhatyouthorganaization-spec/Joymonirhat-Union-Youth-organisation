## 🛠️ গিটহাবে এরর আসার কারণ ও যেভাবে ফিক্স করা হয়েছে (Error Fix Summary)

পূর্বে যখন জিপ (ZIP) ফাইল ডাউনলোড করে গিটহাবে বা লোকাল কম্পিউটারে রান করার চেষ্টা করেছিলেন, তখন যে সমস্যাগুলো হয়েছিল এবং আমরা কোডে যেভাবে সম্পূর্ণ সমাধান করেছি:

1. **`npm install` এ ডিপেনডেন্সি কনফ্লিক্ট (ERESOLVE Error) সমাধান:**
   - **আগের সমস্যা:** `package.json`-এ আলাদাভাবে পুরনো `esbuild` ভার্সন ছিল, যার কারণে Vite 8 এর সাথে কনফ্লিক্ট তৈরি হয়ে `npm error code ERESOLVE` আসত এবং ইনস্টলেশন আটকে যেত।
   - **সমাধান:** অপ্রয়োজনীয় কনফ্লিক্টিং প্যাকেজ সরিয়ে ক্লিন করা হয়েছে এবং একটি সম্পূর্ণ ভ্যালিড `package-lock.json` জেনারেট করা হয়েছে। এখন যে কোনো ডিভাইসে `npm install` বা `npm ci` দিলে ০ (জিরো) এররে ইনস্টল হবে।

2. **GitHub Pages এ ব্ল্যাংক হোয়াইট স্ক্রিন ও ৪০৪ (404 Not Found) সমাধান:**
   - **আগের সমস্যা:** Vite-এর ডিফল্ট অ্যাসেট রুট ছিল `/`, ফলে গিটহাব পেজে (`username.github.io/repo-name/`) আপলোড করলে সমস্ত CSS, JS ও ছবি লোড না হয়ে পেজ সম্পূর্ণ সাদা দেখাত।
   - **সমাধান:** `vite.config.ts`-এ `base: './'` কনফিগার করা হয়েছে। এখন সাইট যেকোনো সাবফোল্ডার, গিটহাব পেজ বা নিজস্ব ডোমেইনে সম্পূর্ণ নিখুঁতভাবে চলবে।

3. **অটোমেটিক গিটহাব ডিপ্লয়মেন্ট (GitHub Actions Workflow):**
   - **যুক্ত করা হয়েছে:** `.github/workflows/deploy.yml` যুক্ত করা হয়েছে। ফলে আপনি গিটহাবে ফাইল পুশ করলেই স্বয়ংক্রিয়ভাবে গিটহাব পেজে লাইভ ওয়েবসাইট চালু হয়ে যাবে।

## 🚀 আপনার কম্পিউটারে চালানোর সহজ নিয়মাবলী (Local Setup)

### প্রয়োজনীয় সফটওয়্যার:
- আপনার কম্পিউটারে **Node.js** (v18 বা তার পরবর্তী ভার্সন) ইনস্টল থাকতে হবে। (ডাউনলোড লিংক: https://nodejs.org)

### ধাপ ১: প্রজেক্ট ওপেন করুন
ডাউনলোড করা ZIP ফাইলটি আনজিপ (Extract) করুন এবং টার্মিনাল বা VS Code-এ ফোল্ডারটি ওপেন করুন।

### ধাপ ২: ডিপেনডেন্সি ইনস্টল করুন
টার্মিনালে লিখুন:
```bash
npm install
```

### ধাপ ৩: ডেভেলপমেন্ট সার্ভার চালু করুন
টার্মিনালে লিখুন:
```bash
npm run dev
```
এরপর ব্রাউজারে `http://localhost:3000` এ প্রবেশ করলে ওয়েবসাইট দেখতে পাবেন।

### ধাপ ৪: প্রোডাকশন বিল্ড তৈরি করুন
```bash
npm run build
```
বিল্ড হওয়া ফাইলগুলো `dist` ফোল্ডারে জমা হবে।

## 🌐 গিটহাবে আপলোড করার সহজ কমান্ড (Push to GitHub)

আপনার প্রজেক্ট ফোল্ডারে টার্মিনাল ওপেন করে নিচের কমান্ডগুলো দিন:

```bash
git init
git add .
git commit -m "Initial release of JUYO official portal"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
git push -u origin main
```
*(উল্লেখ্য: `YOUR_USERNAME` এবং `YOUR_REPOSITORY_NAME` এর জায়গায় আপনার গিটহাবের নাম ও রিপোজিটরির নাম বসান)*

## ⚡ GitHub Pages-এ সম্পূর্ণ ফ্রিতে সাইট লাইভ করার নিয়ম

1. আপনার গিটহাব রিপোজিটরিতে যান।
2. উপরে **Settings** ট্যাবে ক্লিক করুন।
3. বাম পাশের মেন্যু থেকে **Pages** এ ক্লিক করুন।
4. **Build and deployment** সেকশনের **Source** ড্রপডাউনে **GitHub Actions** সিলেক্ট করুন।
5. ব্যস! আমাদের যুক্ত করা `.github/workflows/deploy.yml` ফাইলটি স্বয়ংক্রিয়ভাবে রান হয়ে ২ মিনিটের মধ্যে আপনার সাইটের একটি লাইভ লিংক দিয়ে দিবে:  
   👉 `https://YOUR_USERNAME.github.io/YOUR_REPOSITORY_NAME/`

## 📁 প্রজেক্ট স্ট্রাকচার (Project Structure)

```text
├── .github/workflows/deploy.yml  # GitHub Actions অটো ডিপ্লয়মেন্ট কনফিগারেশন
├── public/                       # লোগো ও মূল স্থির ছবিসমূহ (Static Assets)
├── src/
│   ├── assets/images/            # প্রজেক্ট ও কার্যক্রমের ব্যানার ছবি
│   ├── components/               # রিয়্যাক্ট কম্পোনেন্টস (Hero, Leadership, Wards, etc.)
│   ├── data/organizationData.ts  # সংগঠনের সকল তথ্য, কমিটি, ৯টি ওয়ার্ড ও নোটিশ
│   ├── types.ts                  # টাইপস্ক্রিপ্ট ইন্টারফেস ও ডেটা টাইপ
│   ├── App.tsx                   # মূল অ্যাপ কন্টেইনার
│   └── main.tsx                  # রিয়্যাক্ট এন্ট্রি পয়েন্ট
├── package.json                  # প্রজেক্ট ডিপেনডেন্সি ও স্ক্রিপ্ট
├── tsconfig.json                 # টাইপস্ক্রিপ্ট কনফিগারেশন
└── vite.config.ts                # Vite কনফিগারেশন (base: './' সহ)
```
